LOVELYCS — портфолио веб-разработчика

Как открыть локально:
1. Распакуйте архив.
2. Откройте папку lovelycs-portfolio.
3. Запустите index.html в браузере.
4. В разделе «Портфолио» нажмите «Смотреть» — откроется отдельный демонстрационный сайт.

Проекты:
- projects/north-barber — концепт сайта барбершопа; форма записи демонстрационная.
- projects/form-detailing — концепт сайта автодетейлинга; форма заявки демонстрационная.
- projects/mono-store — концепт магазина; корзина работает локально, но оплата и доставка не подключены.

Редактирование:
- index.html — главная страница и тексты.
- style.css — дизайн главной страницы.
- script.js — меню и анимации.
- В каждой папке projects свой index.html, style.css и script.js.

Telegram для связи: https://t.me/lov3lycs

Для публикации всей папки на Vercel используйте её как один проект (корень — lovelycs-portfolio), чтобы внутренние ссылки projects/... работали.
Демо-проекты не являются реальными клиентскими заказами.

Фотографии пользователя добавлены в assets каждого демонстрационного проекта и используются в карточках портфолио.
