LVCS.STUDIO — портфолио цифровой разработки

Локальный запуск:
1. Распакуйте архив.
2. Откройте папку lovelycs-portfolio.
3. Откройте index.html в браузере.

Структура:
- index.html — главная страница портфолио.
- style.css — оформление и адаптивная версия.
- script.js — мобильное меню, год в подвале и эффекты появления.
- projects/north-barber — демонстрационный сайт барбершопа.
- projects/form-detailing — демонстрационный сайт детейлинг-студии.
- projects/mono-store — демонстрационный магазин.

Важно:
Все три проекта — демонстрационные концепты. Не следует представлять их как реальные клиентские заказы. Для MONO указаны ограничения локального хранения; полноценная торговля требует серверной части, защищённой авторизации, оплаты и доставки.
